# Telegram Channel Publisher

> Lightweight Telegram channel publisher built with Cloudflare Workers.

## فارسی 🇮🇷

Telegram Channel Publisher یک ابزار سبک برای انتشار محتوا در کانال تلگرام است که با Cloudflare Workers ساخته شده است.

### نسخه 2.0.0

نسخه دوم پروژه، نسخه ارتقایافته Telegram Channel Publisher است که همچنان بر رویکرد سبک و ساده پروژه تمرکز دارد.

این نسخه آخرین نسخه پایدار پیش از بازطراحی معماری پروژه در نسخه 3 است.

### وضعیت

**v2.0 — Stable**

## English 🇬🇧

Telegram Channel Publisher is a lightweight Telegram channel publishing tool built with Cloudflare Workers.

### Version 2.0.0

The second release is an upgraded version of Telegram Channel Publisher while keeping the project's lightweight and simple approach.

This is the final stable release before the architectural redesign introduced in version 3.
